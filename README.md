# CR Arena

皇室战争（Clash Royale）like 的 1v1 实时对战游戏，使用 **Bevy 0.19 + Rust** 开发，联网采用**确定性帧同步（lockstep）**——网络只同步操作指令，两端各自跑出逐比特一致的模拟。

## 特性

- **完整对战循环**：选卡 → 攒圣水 → 出牌 → 兵种攻防 → 推塔 → 结算
- **卡牌系统**：4 种卡（骑士/骷髅军团/火枪手/巨人），8 张牌库循环，圣水费用，放置时间与虚影
- **战斗 AI**：索敌/目标锁定（被打断才切换）、质量加权转向力推挤、桥道路径、近战/远程
- **对局规则**：3 分钟常规（末分钟双倍圣水）→ 2 分钟加时猝死 → 拼血阶段 → 结算特效（弹出大字 + 持续烟花）
- **帧同步联网**：30Hz 确定性锁步、中继服务器、逐帧哈希防失同步
- **断线重连**：token 认座、指令日志、追帧恢复；双方离线对局冻结可续命（空帧免服务器模拟）
- **录像回放**：对局自动存档（客户端 + 服务器双份）、回放模式支持暂停/倍速/seek、版本校验

## 快速开始

```bash
# 构建
cargo build

# 单机模式（直接玩，自动检测连不上中继时进入）
cargo run

# 联机对战：先起中继，再开两个客户端（同机测试必须区分 token）
cargo run --bin relay
PLAYER_TOKEN=111 cargo run
PLAYER_TOKEN=222 cargo run

# 指定服务器和房间
RELAY_ADDR=服务器IP:9700 ROOM=2 cargo run

# 录像回放（空格暂停，1/2/4/8 倍速，左右键 ±10 秒）
REPLAY=replays/xxx.cr cargo run
```

## 操作

- **鼠标左键**：在可放置区域（绿色）部署当前选中的卡
- **点击卡槽** 或 **按 1~4**：选卡（选中金框高亮，圣水不足置灰）
- 推掉敌方一侧公主塔后，可在该侧敌方半场部署（CR 规则）

## 技术要点

- **确定性帧同步**：模拟跑在独立的 `SimTick` 调度（固定 30Hz），禁真实时间/随机数；指令打帧号经中继交换，屏障对齐；每帧互发状态哈希防失同步
- **重连与回放共用机制**：对局状态 = 初始状态 + 全部指令，追帧/回放都是重放指令流
- **服务器零模拟**：中继只做转发和日志保管，双方离线时空帧由重连方追帧时自行模拟
- **卡牌数值**：`assets/cards.json` 收录 121 张官方卡牌数值（`tools/scrape_cards.py` 抓取）

## 项目结构

```
src/
├── main.rs        # App 装配（插件/资源/系统注册）
├── constants.rs   # 全部数值调参（SIM_VERSION/地图/战斗/卡牌/计时）
├── components.rs  # ECS 组件与资源
├── arena.rs       # 竞技场场景（相机/灯光/塔/河道/桥）
├── combat.rs      # 战斗核心（AI/推挤/子弹/碰撞/结束判定）
├── cards.rs       # 牌库循环、出牌、部署区域规则、卡槽 UI
├── elixir.rs      # 圣水系统
├── match_flow.rs  # 对局计时、结算特效
├── net.rs         # 帧同步客户端（屏障/哈希/断线处理）
├── replay.rs      # SimTick 调度、追帧/回放、录像
├── protocol.rs    # 网络报文与录像格式
└── bin/relay.rs   # 中继服务器
```
